# Guitar Trainer working rules

Read runbook.md before editing. It records current behavior, verified sources, validation status, and missing content.

- Work in the existing vanilla-JavaScript app. Preserve navigation, data IDs, and the localStorage identity.
- Ground changes in the actual files. Do not invent paths or claim planned content exists.
- Blues is the active personal-use scope. Keep unrelated genre packs parked.
- Song variants keep the same learning activity. Only tempo, duration, and cleanliness scale.
- Displayed chords and BPM must match the accompaniment. A matching key alone is insufficient.
- Use YouTube embeds with external fallbacks. No synthetic backing or DAW workflow.
- Keep left-handed diagrams and an independent, persistent mirror preference.
- No unsolicited redesign, framework migration, dependencies, or unrelated refactors.
- Preserve existing progress. Verify the affected flow on mobile before delivery.
- Record changes, validation results, and remaining gaps in runbook.md. Never report an untested build as working.
